=============================================================
EMIRATES SECRETARIAL SERVICES (ESS) - VIDEO ASSETS DIRECTORY
=============================================================

This directory is dedicated to hosting video files for the ESS & Karama Business Center website.

Location:
  /public/assets/videos/

Currently active video:
  - center-tour.mp4  (1080p Full HD Walkthrough of the center)

How to upload a new video:
1. Upload your video file (MP4 format recommended, H.264 encoding).
2. To replace the current tour video, name your file "center-tour.mp4".
3. To add additional videos, place them here and reference them as "/assets/videos/your-video-name.mp4".

Supported Formats:
  - MP4 (.mp4) - Recommended for universal desktop & mobile compatibility
  - WebM (.webm)
  - QuickTime (.mov)

Web URL Access:
  Any video placed in this folder is automatically served statically at:
  https://ess.ae/assets/videos/<filename>
